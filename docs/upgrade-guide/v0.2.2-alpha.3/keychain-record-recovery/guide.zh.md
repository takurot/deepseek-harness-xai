# 降级前恢复 Keychain 记录

[English](guide.md) | 中文

## 变更

可选的 credentials-keychain 提供方在更新记录和索引前保存待处理事务。它在启动和后续记录操作前完成中断的事务。提交失败报告存储结果未知，而不暗示凭据未改变。旧提供方不理解待处理事务，也不参与 OS 用户/服务写锁。

## 迁移

1. arm64 或 x64 之外的 Linux 架构继续使用 `credentials-local`，因为尚无预构建 POSIX 锁绑定。升级前停止使用同一 Keychain 服务的旧版进程和外部写入方。更新后的进程使用固定的 OS 用户/服务锁标识；不同 `DSH_HOME` 不能隔离同一服务的写入。
2. 记录操作失败时，重新打开更新后的提供方，检查 `readRecord` 和 `listRecords` 后再重试。不会自动重复 mutation 回调。
3. 降级或通过旧提供方访问该服务前，让更新后的提供方成功恢复。确认预期记录与列表条目一致。恢复因事务损坏而拒绝时，保留存储；修复需要检查受影响条目，且不得在诊断中暴露其值。

锁获取默认等待 30000 毫秒，可通过 `cordis.yml` 中的 `lockWaitMs` 设置正安全整数。超时不会启动 mutation；释放提供方会取消获取等待，但不会强制终止已开始的回调。
